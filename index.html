Tools I built for the job.

Two analytics platforms for Primavera P6 programmes — one a web application that reads exports directly, one a Power BI programme-controls dashboard. Both grew out of the same question: can this programme actually be trusted?

Web application Python · React

P6 Schedule Analytics & Forensics

Drop in a Primavera .xer or .xml export and get the whole progress picture in seconds — no P6 licence needed. It recomputes the critical path on the file's own calendars, so it shows where the stored float disagrees with the logic.

  • Earned value & earned schedule — SPI(t), SV(t), forecast finish
  • DCMA 14-point assessment with drill-down to each offending activity
  • NEC4 clause 31 & 32 compliance checks for programme submission
  • Monte Carlo QSRA, windows delay analysis and trend across updates
  • XER repair — fix logic defects and write a corrected file, every change reviewed first
