Sign in

This panel changes the live website, so it only opens for the account that owns it. Sign in with a GitHub token that can write to rauf007-fusion.github.io.

How to create the token (two minutes, once)
  1. Open GitHub → new fine-grained token, signed in as rauf007-fusion.
  2. Name it Portfolio site admin and pick an expiry — 90 days is sensible.
  3. Under Repository access, choose Only select repositories → rauf007-fusion.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Generate the token, copy it and paste it above.

The token stays in this browser — for this tab only, unless you tick Remember — and is sent only to GitHub (api.github.com). Scoped like this it can change files in this one website and nothing else in your account. Don't tick Remember on a shared computer.
